ABOUT:
Decoy Enterprise is a hardened Windows domain & web content access control 
filter designed for office workstations, educational labs, and shared computers. 
It provides tamper-proof hosts-level domain filtering across all browsers with 
a master administrator password lock to prevent unauthorized uninstallation or bypass. 
Includes Viewer Mode privacy masking that completely conceals sensitive and adult 
domain keywords behind clean generic placeholders.

DEFAULT ADMINISTRATOR CREDENTIALS:
- Administrator Username: MRC IT
- Default Master Password: it@MRC
(You can change the master password at any time inside the Admin Dashboard).

FEATURES:
- Tamper-proof password-protected uninstallation and bypass prevention.
- Categorized domain blocking: Social Media, Streaming, Gaming, Explicit, VPN/Proxy, Torrents, Telemetry.
- Viewer Privacy Mode with automatic domain masking (e.g. f*******.com).
- 100% kernel-level hosts filtering: Works across Chrome, Edge, Firefox, Brave without browser extensions.
- Silent 10-minute session auto-lock to Viewer Mode.
- Permanent backend audit logging in C:\ProgramData\Decoy\audit.log.
- Safe automated hosts backup and instant rollback on authorized uninstall.
- Zero network adapter interference: Uses local loopback resolution only (0.0.0.0 and ::1).

INSTALLATION:
1. Extract 'DecoySetup.exe' from this ZIP package.
2. Double-click 'DecoySetup.exe' and approve the UAC elevation prompt.
3. The setup installs Decoy into Program Files, creates Desktop & Start Menu 
   shortcuts, and registers in Windows Apps & Features.
4. Launch Decoy from your Desktop. Log in with master password 'it@MRC' to configure.

Click 'More info' -> 'Run anyway'.
